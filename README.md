# Elevator - Smart Notes
Your notes, elevated — smart offline, powerful in the cloud.
Built for #BuildHybridAI 2026 with Firebase AI Logic Hybrid Inference.
## How it works
- OFFLINE MODE - Short notes run on-device with Gemini Nano. Works Without Internet.
- ONLINE MODE - Synced Everywhere.
- CLOUD MODE - For Long Documents. Long docs use Gemini Flash for summary, outline, and mindmap.
- SUMMARIZE - Instant Summary in 0.8s.
